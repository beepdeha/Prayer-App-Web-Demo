# Madinah Islamic Centre — Prayer Times (Web test build)

A shareable test version of the Madinah Islamic Centre (Rotherham) app: prayer
times, monthly timetable, events, announcements (reminders / Janaza /
madrassa), and a masjid & business directory.

**Live test app:** https://beepdeha.github.io/Prayer-App-Web-Demo/

Open it on a phone; on iPhone you can add it to the home screen from Safari
(Share → *Add to Home Screen*) to use it like an app.

## Notes

- This is the browser build, for trying the app out before it is in the app
  stores. Push and on-device prayer reminders are **not** included here —
  those need the native app.
- Prayer times are bundled and work offline. Events, announcements and the
  directory load live from the masjid's own Firebase project, so anything
  posted from the control panel appears here automatically.

Built from the `www/` folder of the `app/madinah` branch of the main app repo.
(Until November 2026 this site carried the Dar Ul Uloom test build.)
